# Athènes en famille

Le programme partagé du voyage à Athènes, du 22 au 26 décembre 2026.

Lien à partager : https://jaywizar.github.io/Athenes-Holidays/

- Chacun entre son prénom à la première visite, sans compte à créer.
- « ✨ J'ai une idée cool » pour proposer un resto, une activité, une visite ou un verre.
- 👍 Je kiffe / 👎 Bof, pas chaud pour donner son avis.
- La carte montre le logement et les lieux proposés.

## Fichiers

- `index.html` : la page et son style.
- `app.js` : le fonctionnement de la page et la configuration Firebase (en haut du fichier).
- `firestore.rules` : les règles de la base Firestore, à coller dans la console Firebase (onglet Règles). L'accès s'arrête le 31 janvier 2027.

Les données (idées, avis, dates) sont dans Firestore, projet `athenes-2026`, pas dans ce dépôt.
